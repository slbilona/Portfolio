# Portfolio d'Ilona

Bienvenue sur mon portfolio personnel ! Ce site présente mes projets, mes compétences et permet de me contacter directement via un formulaire fonctionnel.

## 🌐 Démo en ligne

Le site est entièrement déployé sur **Vercel** :  
[Voir le site](https://selbonne-ilona.vercel.app)

## 🛠️ Technologies utilisées

- **Frontend** : React, Tailwind CSS  
- **Backend** : Node.js (API serverless pour le formulaire de contact)  
- **Déploiement** : Vercel  
- **Formulaire de contact** : envoi des messages via Mailgun  

## 💡 Fonctionnalités principales

- Page d’accueil avec présentation et projets
- Formulaire de contact fonctionnel
- Design responsive et moderne grâce à Tailwind CSS
